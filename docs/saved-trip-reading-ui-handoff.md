# 我的行程阅读界面调整

> 历史快照：本页的版本、测试数、端口、未提交/无Git提交与验收状态对应页内日期，不代表当前状态。当前源码和回归口径见[维护基线](../README.md#verification-baseline)；本机证据未随仓库发布。

## 范围与问题

本次按用户反馈优化 `/my-trips` 及 `/trip/:id` 的保存结果阅读界面。在本地 15173 的青岛双人行程 `/trip/2` 复现：JourneySummary 全量正文位于导航之前，且 `color: #222` 导致暗色背景上不可读；概览重复输出整段说明，其他分块仍使用旧色块、直角边框。

## 实现

- Result 将摘要、导航和阅读内容分层；概览为日期卡片与待确认事项，点击日期打开对应的每日面板。
- 往返交通独立入口，分去返程卡片展示日期、站场、时间、同行总价、暂定/已订状态及报价来源；接驳、原报价备注、附加费用、票务条件按需展开。缺失每日窗口显示尚未核对。
- 完整行程说明、每日说明、费用缺项可展开；旧来源说明仍受 provenance 保护，外部名称与说明继续纯文本呈现。
- 费用页先展示已知小计/预算上限/完整性，再展示分类费用及图表；没有把未知费用当免费，也不把不完整预算标为上限内。
- 统一每日、住宿、餐饮、地图、天气分块的表面/文字主题色。HotelCard、MealCard 的固定文字色同步替换，保证嵌套详情暗色可读。
- 手机导航为两行可见入口；列表添加真实详情链接，修整操作按钮。页签淡入和日期卡片反馈保留减少动态效果支持。
- 导出模式自动展开本次新增的折叠信息及所有天，背景跟随当前主题。新增导出展开状态单测；未重新执行图片/PDF下载验收。

## 2026-10-24 浏览器续验与修复

按用户要求重新从「我的行程」进入青岛行程2，在手机深色模式实际阅读每日安排、展开交通条件、去费用核对再返回。复现并修复：

1. 长行程下半段丢失分块导航：导航固定在64px应用顶栏下，手机两行入口、每个触控按钮至少44px高。
2. 切换后原展开信息重置：阅读面板首次访问才挂载，此后隐藏而不销毁，保留当天选择、说明和交通/费用折叠状态；未激活面板不出现在可访问树中。
3. 长短面板切换造成滚动位置偏移：使用普通文档流锚点定位内容起点，停用容器浏览器滚动锚定，避免对sticky位置计算偏移。切换后聚焦当前导航，键盘Enter操作复验。
4. 320px顶栏品牌及导航折行：窄屏调整间距与品牌字号，均维持单行。

预算图表观察容器尺寸，只在可见宽度为正时resize，支持隐藏期间从手机改为桌面后再显示。保留轻微面板入场动效和prefers-reduced-motion支持。
