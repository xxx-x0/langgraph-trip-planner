## 当前实施：网站查询与本地导入（LTP-25）

草稿页支持铁路跳转12306、航班跳转携程，携带日期和已匹配的起终点；未知地点只提供网站入口和条件复制，不替换成附近机场。铁路站名使用12306公开静态资源的3404条名称与电报码；航班收录35个国内城市代码。页面明确要求在目标网站核对人数及成人、儿童、婴儿票种，携程链接默认1成人。

2026-10-16真实浏览器核对了12306上海—北京、2026-10-20，以及携程杭州—北京、2026-10-17，均显示对应日期和地点。此证据只确认这些页面的预填行为，不代表覆盖所有城市、保证后续URL稳定或取得票务API授权。未抓取页面私有查询接口，未导入网站报价。

粘贴车票文字后仅在浏览器解析，核对日期、站点、人数、金额口径与来源后加入新备选；再使用既有费用/门到门时间/折腾程度比较、影响预览与确认保存。原文不进入API或持久化；导入时间不是供应商报价时间。税费、接驳、行李和退改未知则保持未知。实现、实际跳转与隔离示例证据见 [LTP-25交接](ltp25-handoff.md)。

以下保留原评估供未来重新决策，本轮不执行申请。两页提供“注册→申请和认证→试用→购买”的流程；公开“查得计费”不是具体套餐承诺。航班搜索页显示的最低单价不能作为当前账户的结算价。申请后在平台“数据中心／我的API”获取各自的key，或提供获授权的MCP配置。密钥只写后端本机环境，不写前端、Git、Nexo或聊天正文。当前代码尚未消费聚合key，避免仅填配置就误以为接入完成。

## 其他候选与限制

- **RollingGo**：[Flight MCP 发布页](https://www.modelscope.ai/mcp/servers/RollingGo/RollingGo-Flight-MCP)仍显示匿名地址 `https://mcp.rollinggo.cn/mcp/flight`，但本机初始化实际返回HTTP 401。公共边界再次探测得到 `authentication`、一次尝试、零报价。官方[航班产品页](https://global.rollinggo.store/solutions/flight/)提供[申请入口](https://partner.rollinggo.ai/register?lang=en)；[工具文档](https://rollinggo.store/docs/mcp-docs/mcp-tool-reference/)的搜索索引还提示航班维护，直接打开又出现文档空间缺失。因此先确认航班恢复及权限，再申请，不把酒店key可用推断成航班可用。航线覆盖、税费/行李、人数报价、可售日期与收费均未实测。
- **Skyscanner**：[申请与鉴权](https://developers.skyscanner.net/docs/getting-started/authentication)需要合作审核和API key。适合比价跳转；[Live Prices](https://developers.skyscanner.net/docs/flights-live-prices/overview)分create/poll，不能只拿初始子集作完整排名。[行李扩展](https://developers.skyscanner.net/api/flights-live-pricing)需要额外开通。个人项目能否获批、收费和目标航线覆盖待审核，当前仅文档评估。
- **Duffel**：[注册指南](https://duffel.com/guides/getting-started)区分test/live，真实模式需要账户激活及业务身份核验。其[offers契约](https://duffel.com/docs/api/offers)提供全体乘客含税总价、条件和失效时间，附加服务另计；测试token不能证明真实报价。官方[费用页](https://duffel.com/pricing)列出超出1500:1查询/订单比后的每次查询费用，查询型产品需先确认费用与准入；不是“只查询永久免费”。国内航线覆盖须用正式权限实测。
- **携程商旅**：[开发者平台](https://openapi.ctripbiz.com/)是企业合作线索。公开入口不足以确认个人可直接领key、仅查询权或费用；未将其列为即刻可用服务。
- **12306**：[官网](https://www.12306.cn/index/)保留用户查询入口。[官方售票规则](https://kyfw.12306.cn/otn/gonggao/saleTicketMeans.html?linktypeid=means1)载明15天（含当天）预售及调整公告。未找到本项目可直接使用的官方开放查询契约，不调用网页私有接口，也不把第三方包装当成官方稳定API。

## 若未来重新授权接入：验证清单（本轮不执行）

先核对供应商展示许可与字段口径，再实现只读适配；不加载订票/支付工具。API或MCP均经过现有公共期限、取消、有限重试、脱敏日志，不缓存实时价或失败。未知价格/条件保留为空，参考价不能升级为可买报价。

至少六组真实查询：上海—北京（近日期1成人/另一日期2成人），上海—成都（近日期1成人/较远日期成人+儿童），上海—苏州（两日期及不同人数/席别）。航班与铁路分别核对返回时刻/时区、日期可售范围、人数口径、价格税费、行李、退改和余票。超预售期、空结果、401/429/超时另测。原响应脱敏留证；儿童或多人报价不支持时明确降为参考，不按成人单价无提示乘人数。

证据：仓库外 `2026-10-16-ltp18-ltp19/live-source-probe.json`。六组真实票务查询尚未执行。当前比较功能使用用户手动记录；测试样例和历史POI/路线回放均不能充当真实票务数据。
