## 记录与分诊规则

每个独立现象使用稳定编号 `NXUSE-001`。重复发生时追加发生日期、请求回执和验证结果，不覆盖首次证据。记录人先保留操作、预期、实际、影响、最短复现和证据；再标记“产品缺陷待确认 / 体验建议 / 连接或环境 / 操作或代理流程问题”。复现成功只证明现象存在，不能代替根因判断。

影响等级按实际后果：P1 为数据丢失或无替代路径的工作阻断，P2 为可恢复的阻断或明显误导，P3 为额外操作或可理解性问题。状态使用待分诊、待复现、已复现、已缓解、待修复、待验证、已关闭。缓解后仍保留改进建议；产品修复后用相同条件复验，追加结果再关闭。

证据可包含脱敏 MCP 请求/回执、页面截图、日志、时间与版本。删除 Authorization、令牌、密钥和无关个人信息；不复制凭据文件。Nexo 版本未知时写未知，不猜测。此台账不授权修改 Nexo。
