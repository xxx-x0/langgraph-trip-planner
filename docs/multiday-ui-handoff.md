# 多日旅行前端体验更新 · 2026-10-20

> 历史快照：本页的版本、测试数、端口、未提交/无Git提交与验收状态对应页内日期，不代表当前状态。当前源码和回归口径见[维护基线](../README.md#verification-baseline)；本机证据未随仓库发布。

用户本轮明确要求改善多日旅行的视觉与操作体验。此次只修改前端展示和导航，沿用原规划、查票、预览、保存接口；保留所有既有未提交成果，不创建 Git 提交。

## 可见变化

- 多城市页面分为「行程总览、城市与住宿、城际交通、费用与待办」。总览以路线卡、已填交通段数、已知费用及待办数量开场，选择城市与日期后只展示当天保存的时间轴。当天说明按需展开，路途、游览、正餐、休息和空档保留原事实。
- 城市编辑改为停留卡；房间/儿童、休息、手动住宿等低频输入收起。交通段可直接点选，保留浏览器助手、文字导入及手工备选。
- 切换工作区不卸载表单和查票工具，不丢失当前输入。未保存修改显示底部操作条；预览在所有工作区可见并获得焦点。已订确认、旧预览失效、保存失败保留和只读版本规则继续沿用。
- 单城市每日草稿收起查票比较，增加逐日定位导航，降低卡片和编辑区的边框强度。顶部公共导航增加「多日旅行」，统一轻量样式，并为移动端图标提供可访问名称。
- 多城市支持浅色/暗色及小屏布局。没有新增图片、第三方字体、框架依赖或接口。
