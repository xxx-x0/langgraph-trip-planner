## 实际操作与数据保留

1. 创建五日旅行、获取并保留苏州休息建议。
2. 苏州真实发现景点，选择留园、平江路、拙政园，确认按天分配，生成酒店/餐厅与逐日路线。城市工作副本 `2339e6d103b3401d974f0369701ed9eb`。
3. 第一天采用11:30晚出发建议并锁定留园；锁定后删除按钮不可用。第二天删除平江路，确认餐次保留后恢复景点。三天全部装配，同步到整趟。
4. 手动填写「流程示例-非真实车票」苏州→杭州21:00～22:00，金额未知，来源说明明确仅用于界面验证。真实预览指出苏州回酒店18:30～18:45占用出发预留，以及杭州含缓冲后没有可用时间；保存为冲突草稿后移除此段、再次预览并确认。最终无测试班次、票价或交通费用注入。
5. 杭州真实景点发现，选择胡雪岩旧居、西湖、雷峰塔，逐日生成。城市工作副本 `240cc15e558c44c698e3482ea6195136`。第一天午餐通过候选面板换为「吉祥馄饨(杭州胡雪岩故居景区店)」，实际地图重算保存成功；已知营业时段冲突候选按钮不可选。
6. 手机端同步杭州，整趟版本5；核对费用/待办并保存为只读版本6，刷新重新读取，城市定位、每日事实及只读入口正常。
7. 独立只读API回读86项通过，涵盖整份计划/城市快照/汇总、6个城市日的景点/餐饮/酒店/路线/时间轴/锁定删除/开始时间/事实说明、休息、餐厅替换、预算缺项和重复读取稳定性。最终核对阶段读取的原只读样本 `mc_d4e06425f63f49d7b0e7d3ad1f4f3fa6` 内容保持一致。
