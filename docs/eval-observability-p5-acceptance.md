# P5 验收矩阵：证据状态与人工判断分开

日期：2026-10-25。对照 [原方案 A01～A16](eval-observability-phase1-plan.md#10-验收矩阵)，保留原门槛，不把已缩小的实施范围追认为全部完成。**本表由代理盘点，USER 验收全部待本人判断，不能用工程测试替签。** 本轮只整理和核对证据，没有重新运行 P1～P4 全量回归、真实模型或 judge。

状态含义：**证据齐备**＝指定工程范围已有可复核材料，不等于 USER 通过；**部分覆盖**＝原条款仍有缺口；**待人工**＝需要本人审阅/标注；**未执行**＝没有对应记录；**效果未验证**＝不能给业务收益结论。一个条款可同时有多种状态。

三项产品规则已由用户确认（B/A/A为主并按需追问），具体记录见 [PR01～PR03](eval-observability-p5-product-decisions.md)。USER列表示最终是否接受交付，不要求负责人代做全部工程核验或按个人喜好选答案；客观证据由工程准备，偏好审阅依 [分层方案](eval-observability-p5-evaluation-design.md)。原独立人工计算/校准要求保留，不因分工调整就自动通过。

本次补充 [工程客观核验](eval-observability-p5-objective-evidence.md) 与 [12份偏好规格](eval-observability-p5-preference-specs.md)。A06/A07的工程材料增加，但独立人工核验、固定性字段、参考/评分版本落地及偏好覆盖仍未完成；不把这些新增算术材料计为人工通过或新模型成绩。A08人工小汇总也没有由此代填。
