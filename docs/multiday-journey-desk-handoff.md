## 设计与交互

- AiroGuide 的深炭灰、暖金与半透明层次转为真实工作台；封面使用既有景点资料图，城市、连接点可直接导航。示意路线明确不是地图。
- Flighty 的阶段思路转为“出发前 / 在途中 / 抵达后”：显示已保存的两城当天安排、真实站点班次、可编辑接驳预留；当天编辑返回原交通段。
- Tripsy 的信息组织转为城市导航、日期卡、节奏条和可展开活动；名称、日期、预算、住宿等按需展开。
- 城市停留用比例条与原生滑块分配，支持键盘；节奏与同行人数用选择卡和步进器。变化仍须预览确认，未直接写入后台。
- 交通候选突出班次及关键风险，完整依据折叠。采用后的预览同时展示两城时间轴。未知总票价及紧张余量持续显示。
- 动画用于封面描线、照片淡入、工作区指示器、阶段/日期切换、展开和悬停；支持 prefers-reduced-motion，无滚动劫持。
- 多城进入的每日编辑页沿用深色视觉，其他单城页面保留原主题。

## 发现并修正

- 缓冲按钮置于label造成双触发：改为独立控件容器。
- 手机城市名称折行：明确不换行与最小宽度，小屏仅路线内部可横向滚动。
- 日程预览不直接展示两侧：采用班次时展开双城保存后时间安排。
- 查票入口六字段占据首屏：收为可编辑查询摘要。
- 每日编辑旧白色底板与按钮对比度不一致：限定多城上下文修复。
- 只读城市设置无法展开：只读时直接展示设置内容。
- 预览缺少impacts的兼容数据：容错为空数组，回归覆盖。
