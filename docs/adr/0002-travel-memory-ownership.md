# 旅行记录拥有独立数据与照片原件

2026-11-03，依据用户确认的“回看回忆：地球足迹、旅行相册、简短记录”及第一版实现授权。

旅行记录表示用户确认的实际经历。一次记录拥有城市到访、回忆片段、照片顺序、封面和原件引用；日期保存真实精度，未知日期不补造，同城多次到访不合并为一次。旅行计划只提供补记来源，保存的计划与实际发生的经历各自成立，不将“completed”计划状态当作到访事实，不据此写入或注入偏好。

使用新表 `travel_memories` 保存独立聚合JSON、revision、最近请求标识和时间。新增表由既有启动初始化创建，不迁移旧计划表。原件按SHA-256存储在独立本地目录，缩略图可以重新生成；不把图片塞进JSON、SQLite或localStorage。浏览器IndexedDB只负责尚未提交的草稿及待上传File；正式记录和备份以服务端保存内容为准。

编辑采用SQLite事务中的revision检查。创建ID、更新请求ID和照片ID支持响应丢失后的重复请求；冲突必须由用户核对后继续，不自动覆盖。旅行、照片和片段用软删除保留，恢复片段时照片关联仍存在。物理原件不提供自动清理，代价是回收站与未关联对象会占用磁盘，需要后续设计显式清理流程。

ZIP备份自包含记录清单和原件，包含回收站。恢复先校验文件路径、清单关系、字节哈希与解码结果，再展示预览；确认时检查预览的数据基线，写入在同一数据库事务中完成。已有内容保持，冲突可跳过或另存确定ID的恢复副本，重复确认/重复导入不无限复制。复制原件先于数据库提交，提交失败可能留下未引用对象，但不会留下半份可见记录。来源计划不打包，缺少原计划不妨碍回忆回看。
