# 携程纯HTTP查询可行性探测

2026-11-02。用户授权验证能否像12306一样从后端直接请求携程网站查询接口。仅使用只读搜索，不注册供应商、不下单、不改应用查询入口或业务库；本轮没有新增依赖、修改依赖锁或创建Git提交。

**最新结果：纯HTTP完整列表仍未跑通，但Chrome原生隐藏页面已完成4次“无需登录、无查询窗口”的真实查询原型验证。** 这是后台运行完整Chrome并读取手机版JSON，不是纯HTTP，也不是已经接入应用。详细结果见下方“原生隐藏页面续验”。

## 条件与观察

固定条件：上海→北京，2026-11-03，1成人。使用全新、未登录的隔离浏览器；没有读取日常Chrome配置或复制用户账号凭据。

普通可见浏览器加载携程列表页成功，从实际网络请求识别到：

```text
POST https://flights.ctrip.com/international/search/api/search/batchSearch
```

业务请求含成人／儿童／婴儿数、城市、日期、舱等和单程标识等字段。实际请求头还出现 `sign`、`rms-token`、`token`、`sessionid`、`transactionid` 等运行时字段；这里只记录字段名，不能据此判定每个字段都必要，也没有生成、破解或伪造这些值。

## 用户约束与匿名路径续验

用户随后明确只接受**无需登录**，并保留无需查询弹窗的要求。已停止登录态路线、关闭登录测试窗口，不再以让用户登录作为本轮推进条件。

匿名续验取得以下实际结果：

- **低价日历纯HTTP可用。** 关闭浏览器后，以全新httpx客户端、无Cookie／运行时签名／登录凭据请求网站实际使用的 `m.ctrip.com/restapi/soa2/15380/bjjson/FlightIntlAndInlandLowestPriceSearch`，HTTP200，394个日期价格条目，其中263个正值。没有航班号或起降时刻，0值没有视为免费。它不能代替行程重排所需的航班列表。
- **手机网页可以匿名查到航班。** 新隔离浏览器正常打开官网公开的手机版入口，经首页搜索北京→上海、2026-11-03，无登录操作，得到 `m.ctrip.com/restapi/soa2/14488/flightListSearchForH5` 的HTTP200响应，`rlt=0`、`rltstatus=0`、211条方案行，包含航班号、机场及完整起降日期时间。方案行可能含中转及共享航班，不是211个独立直飞航班。
- **手机版列表纯HTTP仍未通过。** 关闭该浏览器后，用新httpx客户端直接提交所观察到的业务字段，不携带浏览器head／Cookie／运行头，返回HTTP432；未获得JSON。遇到拦截后没有循环重试其他日期，也未尝试伪造挑战材料。
- **手机版无界面浏览器仍未通过。** CLI无界面深链入口HTTP432。另用项目实际安装的Playwright／Chromium原始默认启动方式测试新匿名context，深链未获得列表响应；再做普通首页→搜索流程对照，首页HTTP432。未增加反检测参数、借用既有用户配置或登录态。这些失败只代表本轮路径，不证明所有客户端永远不可行。

额外留样：`anonymous-calendar.json`、`anonymous-flights-results.json`、`headless-h5-results.json`、`headless-flow-results.json` 及相应可复验脚本。CLI版本可能自带启动参数，最终无界面判断另有项目实际SDK的默认启动对照，不将CLI特定行为直接推断成产品运行表现。

## 原生隐藏页面续验

本机macOS、已安装Google Chrome **156.0.8078.74**。采用Chrome公开CDP的 `Target.createTarget(hidden=true, background=true)`，为每次测试创建全新临时Chrome目录，以本机回环地址临时调试端口连接；不使用日常Chrome资料、扩展、登录态、无界面模式、UA修改或反检测脚本。该参数由[Chrome DevTools官方协议](https://github.com/ChromeDevTools/devtools-protocol/blob/master/json/browser_protocol.json)定义为实验性能力，隐藏target不显示在标签栏，不能直接推断所有Chrome版本／其他浏览器均兼容。

隐藏target在本版本类型为`other`，Playwright没有暴露为普通Page，因此原型使用公开CDP附着该target，操作官网正常城市／日期选择和搜索控件，通过Network事件读取实际JSON。没有修改网站业务请求或生成验证字段。仅以调试管道启动时Chrome拒绝创建隐藏target；最终使用独立临时目录、原生回环调试端口启动，不以早期失败的启动方式作为成功方案。

完整航班列表的纯HTTP查询仍未跑通，匿名初始化成功也不足以完成查询。**但本机的Chrome原生隐藏页面已在原型中满足“无需登录、无需查询弹窗”，不同日期／城市及浏览器重启的4次查询均成功。** 可以据此推进“后台Chrome正常运行官网→读取JSON→候选适配”的应用实现；它继续依赖Chrome运行组件，并不等同12306的HTTP直查。

当前查询入口尚未替换。正式接入仍须补总期限／取消／并发和进程清理、城市及日期控件就绪、未知报价／登录或拒绝的明确失败处理，并完成现有推荐、草稿快照保护、预览、日程重排、待安排、保存刷新的一轮真实联测。多人／儿童、其他系统／浏览器、长期稳定性与含税可购买票价尚未验证，不因本次格式校验而宣称通过。
