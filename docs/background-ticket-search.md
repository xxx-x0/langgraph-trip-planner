# 免扩展后台查票

2026-10-26 新增。本阶段限启动后端的本机单用户，不接付费票务服务，不提供购票或支付。

## 使用

单城草稿和多城市当前交通段均使用“后台查询火车票／机票”。日期、起终点及人数取本段表单；先保存日程修改，多城市先同步城市副本。结果仍经过既有 `/api/tickets/recommend` 的已保存快照核对、明确偏好过滤和最多三项展示，采用须预览确认。

12306 无需新依赖。携程使用可选本机组件，在实际启动后端的 Python 环境执行：

```bash
cd backend
python -m pip install -r requirements-ticket-browser.txt
python -m playwright install chromium
```

`requirements-ticket-browser.txt` 单独固定 Playwright/pyee，使用原 `requirements.lock.txt` 约束既有包；不升级 LangChain/FastAPI 等框架。启动方式仍是 `python run.py`。缺少组件时铁路仍可查，机票提示安装或使用网站备用方式。

携程先尝试无界面读取。未读到匹配列表时显示待处理，不自动声称无票：点击“打开登录／验证窗口”，在启动后端的电脑完成登录、验证码或核对查询条件，再点击“已完成处理，继续读取”。独立浏览器不继承日常 Chrome 登录。无需提供密码给应用，也不复制日常浏览器配置。

默认配置：

| 配置 | 默认值 | 用途 |
| --- | --- | --- |
| `TICKET_BROWSER_PROFILE_DIR` | `~/.local/share/langgraph-trip-planner/ticket-browser` | 本机专用登录目录，目录权限700；不纳入Git |
| `TICKET_BROWSER_CHANNEL` | `chromium` | 可选已安装的`chrome`/`msedge`；同样使用专用目录 |

认证目录包含敏感登录状态，不作为证据、报告或源码附件。查询窗口需桌面环境；云端、多人、远程浏览器交付不在本轮范围。停止查询、过期、被新机票查询替代或后端退出时关闭对应窗口；登录资料留在本机供下次复用。

## 实现边界

- `POST /api/tickets/search` 创建只读内存任务，`GET /search/{id}` 获取状态，`POST /search/{id}/browser` 打开窗口，`POST /search/{id}/continue` 继续，`DELETE /search/{id}` 停止。以上路径均位于 `/api/tickets` 下，仅允许本机来源；不接受任意查询URL、脚本或目录参数。
- 每任务15分钟有效，内存最多16项；重启后旧任务无效。查询执行有总期限、并发和取消，遵守公共外部调用边界；无无限自动重试。新机票查询会停止旧机票任务，专用浏览器串行使用。
- 铁路读取12306网页中的查询路径和公共车站表，再请求JSON余票结果。城市/精确站范围在采样前校验；乘车日期使用查询日，通过历时核对到达时刻，不使用列车始发日作为上车日。公开可识别席别分别形成候选；数字余票少于同行人数不进入候选；候补、无座及未支持席别不包含。票价无法识别时保留null。
- 携程复用项目现有DOM读取器，按原日期和城市核对，只读可识别国内直达列表。最多16轮滚动，稳定3轮停止，最后采样最多80条。未读取到列表、显式空结果、错误三者分开；不绕过网站访问限制。
- 两类均最多返回80个候选，仅表示本次可识别的部分；铁路一个车次可有多个席别。班次/席别/参考价不等于已购、同行含税总额或实时可成交承诺。未知费用继续不计为已知预算。
- 查询结果只存在内存。前端条件或日程改变、停止、过期时撤销旧推荐，忽略迟到返回；推荐与采用仍沿用既有快照检查和确认保存。浏览器扩展、网站跳转、文字导入保留为备用入口。

## 验证记录

最终隔离后端999项通过、4项外部smoke跳过；前端258项通过，类型检查及生产构建通过。新增用例覆盖车站范围、乘车日与跨夜、票价缺失、多人余票、车站表相对路径、异常响应、只读任务、取消/过期、窗口恢复、远程来源拒绝、迟到结果及既有采用流程。全量评估测试有源码冻结检查，运行期间不能继续修改后端源码；首次在编辑期间运行触发了该保护，最终固定源码重跑通过，没有放宽检查。

同一隔离后端的页面机票链路也完成：上海→北京80条候选，按空白已保存安排排除12条，默认展示不同取舍，采用HO1253→预览→确认保存→刷新/API回读。机票样例revision2保留浦东→大兴、2026-10-27 17:50—20:15，planned、ticket_total=null及price_source=unknown；参考起价400元只在说明中。没有将列表起价乘人数计入预算。此链路未调用模型，不能作为AI推荐质量证据。

桌面结果/预览及390px小屏入口已浏览器检查；小屏页面scrollWidth与viewport均为390，无横向溢出。隔离预览前端15176、后端18028，最后重启后健康检查通过，使用本轮源码；旧业务服务未替换。

所有实际查询和页面保存均使用临时SQLite及`output/ticket-search/`专用浏览器目录。新Playwright/pyee只安装到隔离副本`output/ticket-search/venv`，原运行环境、主依赖锁及业务库未变；额外浏览器二进制放在Playwright本机缓存。查询未调用付费票务或新增文案模型，已有未提交成果保留，无Git提交。

本机证据目录：`output/ticket-search/`（不入Git）。模拟HTML/HTTP、登录恢复和异常测试仅证明实现分支，不替代真实网站数据、真实登录或用户体验验收。多城市样例为无景点/酒店/餐饮的空白安排，不证明复杂已有日程适配质量或真实旅行价值。
