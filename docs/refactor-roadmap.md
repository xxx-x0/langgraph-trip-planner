## 依赖评估依据

2026-10-13 本机已安装并验证的版本为 Python 3.12.13、langchain-core 1.4.0、langchain-openai 1.1.9、LangGraph 1.2.4、checkpoint-sqlite 3.1.0、MCP adapters 0.2.2；未安装 `langchain` 主包。当前环境通过 `pip check`，已冻结为 `backend/requirements.lock.txt`，前端沿用现有 package-lock。

同日查询到的版本为 core 1.6.10、openai 1.7.1、LangGraph 1.2.15、checkpoint-sqlite 3.1.2、adapters 0.3.2；这些只是当日版本比较，**不是已验证升级目标**。项目月份较早不足以支持整体重写。

[LangGraph v1 迁移说明](https://docs.langchain.com/oss/python/migrate/langgraph-v1)以兼容为主；本项目的自定义 StateGraph 不因 `create_react_agent` 弃用就需要重写。[原 MCP adapters 仓库](https://github.com/langchain-ai/langchain-mcp-adapters)说明其已停止积极维护，[新 MCP 迁移说明](https://docs.langchain.com/oss/python/migrate/langchain-mcp-adapters)列出了 beta 接口、`langchain[mcp]`、MCPAdapter 与错误行为变化。迁移前须重新核对当时官方要求和服务兼容性，不能直接替换导入后宣称完成。
