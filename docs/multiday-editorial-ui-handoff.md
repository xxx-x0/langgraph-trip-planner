# 多日旅行手册式界面与动效（2026-10-23）

> 历史快照：本页的版本、测试数、端口、未提交/无Git提交与验收状态对应页内日期，不代表当前状态。当前源码和回归口径见[维护基线](../README.md#verification-baseline)；本机证据未随仓库发布。

本轮按用户要求继续提升视觉品质，并在后续明确要求后增加操作动效。用户主观审美和实际满意度仍待判断。

## 设计和交互

- 多城市页面使用暖白纸色、墨绿、暖赭色、宋体标题与细分隔线；减少同权重圆角卡片。公共导航在多城市页面使用对应主题，手机保留文字标签。
- 新增 JourneyCover 路线封面；等高线是装饰示意，并明确标注非地图。点击城市直接定位相应章节。
- 城市目录、日期书签、当天标题、行程时间轴与右侧住宿说明形成主次层级。景点图只使用已存的 image_url，加载失败隐藏；不生成或冒充真实照片。
- 新增按保存时间分配宽度的全天节奏条。点击色块会定位和高亮对应安排，路程项会先展开完整时间轴。游览、餐次、休息和住宿默认保留，路程/等候/空档默认收起并明确显示数量；折叠仅影响展示，未修改任何安排。
- 费用和待办在总览下方保留快捷入口，交通工作区保留独立分段选择、每日安排衔接、查票、手工填写、预览和确认规则。
- 动效：封面线条约 1.1 秒描绘、路线入场；工作区下划线滑动及内容短过渡；日期内容 120 毫秒退出/260～320 毫秒进入；时间轴展开与位移、节奏条展开、定位高亮、预览和未保存操作条入场，以及按钮/图片悬停反馈。无常驻循环动效、额外动效依赖或业务等待。CSS 和主动滚动响应 prefers-reduced-motion。
