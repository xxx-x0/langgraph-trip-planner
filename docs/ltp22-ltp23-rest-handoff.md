## 实现与兼容

`models/rest.py` 定义有日期、时间和稳定标识的 RestPeriod；`services/rest_schedule.py` 将固定休息放入时间轴并检查冲突。多城市停留、城市请求、每日上下文及定稿共享 rest_periods。不同城市同一天的重叠休息也拒绝输入。

`POST /api/multi-trips/rest-suggestions` 返回建议与原因，不写数据库。多城市投影区分计划休息和实际落实，检查抵离窗口；预览和保存沿用整趟 revision/token 事务校验。纯休息日仍提示住宿及正餐缺项。说明根据保存时间轴描述休息与最长的未安排时间，不再建议利用五分钟空档增加活动。

无房故障检查发现报价 amount 为空会遮蔽 unavailable 原因，已修复为明确显示“未返回可售房型，请重新选择住宿”；不将其计为已确认的免费住宿。未改 ORM、依赖锁、原运行环境或业务库，未创建 Git 提交。
