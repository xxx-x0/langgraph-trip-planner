# 查票地点资料

`railStations.json` 是12306公开站名静态资料的名称→电报码映射，用于生成查询网页链接和本地文字识别，不含车次、时刻、票价或余票。

- 来源：https://www.12306.cn/index/script/core/common/station_name_new_v10118.js
- 获取日期：2026-10-16；由12306首页的资源引用确认，3404个唯一站名。
- 原格式按 `@` 分记录、`|` 分字段，取名称（索引1）和三字电报码（索引2）。本地仅保留这两个事实字段。
- 更新时先检查官网实际引用的新资源地址，确认内容是站名资料而非错误HTML；校验每条名称非空、电报码为三位大写字母及总数合理，再替换JSON。不得将空下载或错误响应写入表。
- 更新后运行前端测试、构建，并在官网实际核对至少一条带日期/站点的跳转。网站参数不属于稳定API契约，失效时退回首页和条件复制。

`utils/ticketSearch.ts` 的航班映射为36个国内城市级代码，并非全球机场目录。初次仅杭州—北京预填核对；后续杭州—青岛等查询见带日期的单城交接，仍未逐项实测全部映射。未知城市保留手工查询，不推断附近机场。
